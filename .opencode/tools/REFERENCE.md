# Tool Reference

Supported tools and their usage in Noir skills.

| Tool | Purpose | Install |
|------|---------|---------|
| `nmap` | Port scanning | `apt install nmap` / `brew install nmap` |
| `curl` | HTTP requests | `apt install curl` / preinstalled on macOS |
| `ffuf` | Directory & parameter fuzzing | `go install github.com/ffuf/ffuf@latest` |
| `python3` | PoC scripts, custom payloads | `apt install python3` / preinstalled |
| `jq` | JSON parsing (optional) | `apt install jq` / `brew install jq` |
